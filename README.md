## 🚀 Projetos em destaque

### 💸 [Vexira](https://github.com/GuibasURL/Financas-SaaS): controle financeiro inteligente
App web de finanças pessoais, **publicado na internet**: você envia o extrato do banco (CSV ou OFX), e o app organiza as transações em categorias, mostra gráficos e exporta um relatório em Excel.

* **API** em Python (FastAPI, SQLAlchemy, Alembic) com PostgreSQL e autenticação JWT.
* **Front-end** em React e TypeScript, com dashboards (Recharts).
* **Importação de extratos** de vários bancos, categorização automática e detecção de duplicatas.
* **Qualidade:** testes automatizados (pytest e Vitest) e CI no GitHub Actions, com cobertura mínima de 95% no backend e testes também no PostgreSQL.
* **Segurança:** senhas com bcrypt, limite de tentativas de login, recuperação de senha com token de uso único e isolamento de dados entre usuários validado por testes.
* **Deploy:** Render (API), Vercel (site) e Neon (banco).

🔗 [Acessar o app](https://vexira-financas.vercel.app/) (o servidor é gratuito e o primeiro acesso pode levar cerca de 1 minuto)

**Stack:** `Python` `FastAPI` `PostgreSQL` `React` `TypeScript` `GitHub Actions`
